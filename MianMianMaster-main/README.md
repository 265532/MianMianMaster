# 面面俱到

基于Vue 3和TypeScript开发的智能面试平台，旨在为求职者提供AI驱动的面试模拟、能力评估和职业发展解决方案。

## 技术栈

- **前端框架**: Vue 3.5.25
- **路由**: Vue Router 4.6.4
- **类型系统**: TypeScript 5.9.3
- **构建工具**: Vite 7.3.1
- **UI组件**: Lucide Vue Next 0.575.0
- **图表库**: ECharts 6.0.0
- **样式**: Tailwind CSS 4.2.1

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发环境运行

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 核心功能

- **AI面试模拟**: 提供多岗位、多场景的智能面试模拟
- **能力评估**: 从技术水平、表达能力等多维度评估面试表现
- **岗位匹配**: 结合职业测评和岗位需求，提供精准的匹配度分析
- **能力提升**: 基于评估结果，为用户提供定制化的学习路径
- **面试社区**: 支持用户分享面试经验和学习资源
- **知识库**: 提供面试技巧和技术知识
